# Combat

- `STRIKE_DURATION_MS` (`app/game/constants.ts`) must stay below the shortest gap between two blows, `MIN_ATTACK_TICKS` (`app/game/combat.ts`). A blow's lean has to finish before the next blow starts.
- `GameSession.advanceCooldowns` (`app/game/GameSession.ts`) for the world and `Duel.advanceCooldown` (`app/game/duel.ts`) for the Arena count swing cooldowns down through the same `countDown` (`app/game/ticks.ts`). A plain subtraction of `TICK_MS` leaves a float remainder that holds most whole-tick intervals one tick long, so counting either loop another way makes the Arena measure a different pace from the one the world plays. The exact-tick swing tests in `battle.test.ts` and `duel.test.ts` catch it, and so does "bites at the pace the Arena measures, not the brain's" in `brain.test.ts`.
- `rollAttack` (`app/game/combat.ts`) draws its dice in a fixed order and count whatever the outcome: miss, dodge, damage band, guard, then one draw per authored status. `swingOdds` in `combatMetrics.ts` mirrors that order. Changing the order or skipping a draw conditionally desyncs the two; the draw-count assertions in `combat.test.ts` catch it.
- `rotationOdds` (`app/game/combatMetrics.ts`) prices a body with a weapon in each hand as `Duel` (`app/game/duel.ts`) swings it: each hand in turn, each blow followed by its own weapon's `swingIntervalMs`. Changing how `Duel` picks the next hand or sets the cooldown after a blow desyncs the Arena's per-second figures from the fight; the two-weapon test in `combatMetrics.test.ts` catches it.
- To retune how much a kill is worth, change `XP_PER_DAMAGE` (`app/game/experience.ts`), not `XP_PER_LEVEL_SQUARED` (`app/lib/mastery.ts`). Stored experience is read against the levelling curve, so changing the curve re-levels every saved player.
- `Duel` (`app/game/duel.ts`) applies `GameSession`'s status rules by calling the same functions: `isImmune` (`app/lib/battler.ts`) before a blow's status is granted, `incapacitated` before a fighter swings, and `endOnDamage` when damage lands (both in `app/game/statuses.ts`). A rule written inline in `GameSession` instead is one the Arena does not apply. The full windup a fighter pays after incapacitation is copied by hand: `Duel.dueToSwing` follows `disengage` and the re-arm in `GameSession.tryAttack`.
- `MIN_MASTERY` (`app/lib/mastery.ts`) stays 0 while `MIN_EARNED_MASTERY` is 1. The first is the floor for authored blocks, and raising it to match would re-rate every creature and every Arena fight; the second only clamps what experience reads as.
